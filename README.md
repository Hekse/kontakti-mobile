# Kontakti Mobiili

Tämä repo on Kontakti Mobiilin repo.

## Virallinen käyttötarkoitus

- `index.html` = Kontakti Mobiili -sovellus

## Työskentelysääntö

Älä käytä tätä repoja Opero Ajon korjauksiin tai julkaisuun. Opero Ajo löytyy reposta:

- `Hekse/index.html`
- branch: `main`
- tiedosto: `index.html`

Tämä merkintä on lisätty, jotta Ajo ja Kontakti eivät mene Codexissa tai käsin muokatessa sekaisin.
